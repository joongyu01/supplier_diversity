## 2. 연락처 게시 원칙

구매 담당자가 동명 사업체를 구분하고 실제로 연락·방문할 수 있어야 하므로 **사업자등록 공개정보는 싣습니다.**
1. **대표자·시설장**: 엑셀의 `대표자명`·`생산시설장`을 싣고, 나라장터 업체 기본정보(`ceoNm`)가 있으면 그 값을 우선합니다.
2. **사업장 전화·팩스·홈페이지**: 나라장터 업체 기본정보(`telNo`, `faxNo`, `hmpgAdrs`)와 중증 시트 `전화번호`.
3. **사업장 주소**: 나라장터 업체 기본정보(`adrs`+`dtlAdrs`), 중증 시트 `생산시설의 주소`, 표준사업장 `소재지`. 광역 시도는 별도 `region`으로도 보존합니다.
4. **싣지 않는 것**: 계약담당자 개인 이름·이메일(`cntrctOfclNm`, `cntrctOfclEmail`), 개인 휴대전화.

출처 구분은 `contactSource`(`api` = 나라장터 업체 기본정보, `excel` = 정부권장정책 목록)로 남깁니다.
